# 🌍 Agentic AI Multi-Agent Personalized Travel Planner

## 📌 Project Description

Agentic AI Multi-Agent Personalized Travel Planner is an advanced
AI-powered travel intelligence system that uses multiple AI agents,
vector memory, real-time APIs, and machine learning prediction to
generate smart and personalized travel itineraries. The system
automatically optimizes routes, travel costs, bookings, and schedules
while adapting to weather conditions, safety insights, and user
preferences in real time.

------------------------------------------------------------------------

## 🚀 Key Features

-   🤖 Multi-Agent AI System (Planner, Booking, Weather, Safety,
    Replanner)
-   🧠 Vector Memory Personalization (ChromaDB)
-   📡 Real-Time API Integration (Weather + Travel APIs Ready)
-   📊 ML-Based Travel Price Prediction
-   🗺 Intelligent Route Optimization
-   💰 Dynamic Budget Optimization
-   🎤 Voice Input and Output Support
-   🔄 Autonomous Travel Replanning
